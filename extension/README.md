# Shofiliate Companion Extension

Ekstensi pendamping Google Chrome untuk menjembatani **Web Shofiliate** dengan **Shopee Affiliate Portal**. Ekstensi ini memungkinkan fitur **Auto-Enrichment**: saat Anda mengunggah file JSON dari Shopdora, ekstensi secara otomatis melengkapi data **komisi (%)**, **estimasi komisi nominal**, dan **link affiliate (`https://s.shopee...`)** menggunakan sesi login aktif streamer.

---

## Cara Memasang di Google Chrome / Edge / Brave:

1. Buka browser **Google Chrome** (atau Microsoft Edge / Brave).
2. Kunjungi URL: `chrome://extensions/` (atau `edge://extensions/`).
3. Aktifkan sakelar **Developer mode** di pojok kanan atas.
4. Klik tombol **Load unpacked** di pojok kiri atas.
5. Pilih folder `extension` yang ada di dalam direktori repository ini:
   ```
   c:\Users\Ikhwan Kurniawan\Documents\GitHub\shofiliate\extension
   ```
6. Ekstensi **Shofiliate Companion** kini aktif dan siap digunakan!

---

## Cara Menggunakan:

1. Buka tab baru di browser Anda dan **login ke akun Shopee Affiliate**:
   - Untuk Malaysia (MY): [https://affiliate.shopee.com.my](https://affiliate.shopee.com.my)
   - Untuk Indonesia (ID): [https://affiliate.shopee.co.id](https://affiliate.shopee.co.id)
2. Buka web **Shofiliate** di menu **Import Produk** (`/dashboard/products/import`).
3. Status ekstensi akan otomatis terdeteksi hijau: **"⚡ Shofiliate Companion Terhubung"**.
4. Drag & drop file hasil export dari **Shopdora**.
5. Sistem akan secara otomatis memperkaya 300+ produk dengan komisi dan link affiliate sebelum Anda mengonfirmasi import!
